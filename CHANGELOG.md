# Changelog

## 2.0.0 - 2026-10-11

- Replace one-line command with a menu-driven batch utility.
- Add 5-hour, 1-hour and 60-second shutdown options.
- Add cancellation and explicit scheduling confirmation.
- Remove `/f` (force-close applications) from shutdown commands.
- Document safety considerations and Task Scheduler usage.
- Add non-destructive static tests.
